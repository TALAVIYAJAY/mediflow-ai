# MediFlow AI 🏥⚡

> **Omnichannel Healthcare Triage, Clinical Report Intelligence & Hospital Operations Platform**  
> Built with **FastAPI**, **LangGraph**, **PostgreSQL (`pgvector`)**, **Google Gemini Vision**, **Playwright (RPA)**, and **n8n**.

---

## 🌟 Overview

**MediFlow AI** is an enterprise-grade medical AI ecosystem designed to automate patient intake, clinical lab report analysis, appointment scheduling, and insurance pre-authorization.

### Core Capabilities
- **Omnichannel Patient Intake (Voice & Chat):** Real-time symptom triage with strict emergency safety guardrails.
- **Multi-Modal Diagnostic Analyzer:** Automated biomarker extraction from lab reports and prescriptions using Gemini Vision.
- **Doctor & Operation Scheduling:** Intelligent specialist matching and slot reservation via stateful LangGraph agents.
- **Mediclaim Pre-Authorization:** Policy RAG powered by PostgreSQL (`pgvector`) and automated insurance portal filing via Playwright RPA.
- **Event-Driven Hospital Orchestration:** Seamless integration with n8n for WhatsApp notifications and doctor alerts.

---

## 🛠️ Architecture & Tech Stack

- **Agentic Engine:** LangGraph, LangChain
- **Backend API:** FastAPI (Async)
- **Database & Vector Store:** PostgreSQL with `pgvector`
- **LLM & Embeddings:** Google Gemini (`gemini-2.0-flash`, `text-embedding-004`)
- **Automation / RPA:** Playwright & n8n
- **Validation:** Pydantic V2
- **Frontend (Coming Soon):** Next.js (TypeScript + Tailwind CSS)
